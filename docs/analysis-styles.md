# Analysis templates and skills

The ask-bar Style choice controls response format independently of model choice:
Auto, Plain, Review, Debug, Investigate, or your own saved template/skill.
Auto applies a built-in format to review/debug/investigation queries; simple
questions use the normal concise answer. Model Auto still chooses the model.

My Diary → Saved prompts supports Prompt, Analysis template and Skill/checklist.
**Use style** selects a template for the next ask; it does not submit a question.
Templates are declarative instructions, not executable code or extra privileges.
All source scope, secret handling, role checks and write confirmation remain
authoritative. Saved templates belong to the account's encrypted workspace.

Built-in review/debug skills require cited evidence, actual source coverage,
explicit uncertainty and a useful next action. A format cannot guarantee a
correct verdict; unread files or missing access must remain visible as gaps.
