# Modern chat tables

Chat and formatted-preview tables use a border-light layout: no outer panel or
vertical grid, a subtle header, fine horizontal separators and gentle row hover.
Text and colours follow the active theme. Semantic table markup, alignment and
the focusable horizontal-scroll wrapper remain intact for wide data.

Set `window.AiMateFeatures.modernTables = false` before rendering to retain the
previous table appearance. No stored messages, exports or provider payloads change.
