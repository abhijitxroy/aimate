# Personal-record safety locks

My Diary and To-do open locked. Use the lock icon next to the close button to enable editing/deletion, then click it again to lock. Hover shows the action; the icon uses the current theme's text colour.

While locked, existing-record edits and deletion are disabled. To-do completion changes are also disabled. Copy, view, filter, expand and creation of new entries remain available. Relocking an existing editor makes its fields read-only and disables saving; reopening either dialog locks it again.

These controls prevent accidental UI changes. They do not replace server roles, authentication or encrypted storage, and they cannot cancel a request already submitted while unlocked.
