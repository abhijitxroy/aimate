# Message formatting

Open **Format** above the askbar. The toolbar supports bold, italic, underline, text colour, headings, paragraphs, lists, indentation, code blocks, horizontal rules, tables, quotes and information/warning panels. Wrap changes the editor view; Preview shows the message before sending.

Formatting is stored as portable Markdown text, so copying/exporting/editing retains the original source. Underline uses `++text++`; colour uses `[colour:#79baff]text[/colour]`. These two inline formats accept literal text, not nested formatting. Code fences keep all markup literal.

Raw HTML, arbitrary CSS and embedded remote images remain disabled. Colour values accept only six-digit hex codes. The toolbar is collapsed by default; none of its buttons submits a request.
