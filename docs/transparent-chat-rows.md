# Transparent sidebar chats

Project and chat rows show their icons, names and menu controls without filled
panels. The selected chat uses accent text and a heavier label; keyboard focus
underlines the label. Hierarchy lines, pin ordering, recents and menus remain.
The styling works across the built-in themes and imported theme colours.

Disable independently by setting
`window.AiMateFeatures.transparentChatRows = false` before the module loads.
This restores the existing themed row surfaces without changing any chat data.
