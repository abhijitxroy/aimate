# Vibrant status labels

Compact pills use green for checked success, blue for information, orange for
pending/uncertain work and red for confirmed failure. Classification, callout and
quality labels share the palette. Beige uses darker saturated shades for readable
contrast. Normal text stays clean; labels and wording still reflect evidence.

Confidence and model-assessed scores are not independent verification. The palette
does not create a “Verified” result or change stored assessments.

Disable this presentation module with
`window.AiMateFeatures.vibrantStatusLabels = false` before it loads. Existing
labels and Markdown remain usable. Printed labels use black on transparent.
