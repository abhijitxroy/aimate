# Conversation monogram colours

Open a chat menu → Change icon → Monogram. Choose a colour, or keep Use theme colour enabled. Initials, colour and theme reset persist after restart and are included in encrypted portable backups.

Colours apply only to monogram text and outline. Emoji and the AiMate brand logo retain their original appearance. Each account stores its own conversation styles; the API accepts only six-digit hex colours, never arbitrary CSS.
